# Project Atlas

> **An open, data-driven platform for building interconnected digital gardens.**

Project Atlas is the software platform behind **Thoms Foolery**, an interactive personal website exploring technology, creativity, nostalgia, and personal growth through connected ideas.

Rather than treating webpages as isolated destinations, Atlas treats knowledge as a network. Articles, projects, collections, and experiences are connected through shared topics, themes, technologies, and stories, creating a digital space that rewards curiosity through exploration.

> **Everything is connected.**

---

# Why Atlas?

The modern web is exceptional at delivering answers.

Atlas is designed to encourage exploration.

Traditional websites organize information into categories and menus. Atlas organizes information into relationships.

Visitors may arrive looking for one topic and discover five others.

A story about music may become a story about identity.

A programming project may become a lesson in craftsmanship.

A baseball article may become a memory about childhood.

Those connections are not accidental.

They are the product.

---

# Project Goals

Project Atlas is built around a small number of long-term goals.

- Create digital spaces that reward curiosity.
- Build knowledge as an interconnected network rather than isolated pages.
- Separate content from presentation through structured data.
- Prioritize accessibility, maintainability, and longevity.
- Document every significant architectural decision.
- Grow alongside its creator while remaining adaptable for future implementations.

---

# Atlas Ecosystem

Project Atlas consists of several complementary systems.

| System | Purpose |
| :--- | :--- |
| **Atlas Blueprint** | Defines the philosophy, vision, documentation, and long-term direction of the project. |
| **Atlas Core** | The software engine responsible for transforming structured content into interactive experiences. |
| **Thoms Foolery** | The first public implementation and reference website built using Atlas. |
| **Atlas Framework** *(Future)* | A reusable platform enabling others to build interconnected digital gardens. |
| **DropAnchor** | A personal, password-protected interactive web tool providing guidance during neurodivergent burnout and sensory overload. |

Future versions may introduce **Atlas Studio**, a visual environment for creating and maintaining Atlas-powered websites.

---

# Project Philosophy

Atlas is guided by one fundamental belief.

> **Everything is connected.**

Knowledge becomes more valuable when its relationships are visible.

Instead of encouraging visitors to consume one page at a time, Atlas encourages them to explore how ideas relate to one another.

Every architectural decision should reinforce this philosophy.

# Development Principles

Atlas follows several guiding principles throughout development.

- Documentation before implementation.
- Architecture before features.
- Reusable components over page-specific code.
- Content separated from presentation.
- Accessibility by default.
- Simplicity over unnecessary complexity.
- Long-term maintainability over short-term convenience.
