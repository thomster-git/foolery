# Atlas Content

This directory contains every piece of knowledge that powers Project Atlas.

Each markdown file represents a single Atlas Object.

The build system discovers these objects automatically and converts them into a structured knowledge graph.

Current object types include:

- Articles
- Projects
- Topics
- Themes
- Collections
- Galleries
- Media
- Library Items
- Documentation

The folders underneath this directory are organizational only.

Relationships are defined by metadata, not file location.

As Atlas grows, the build system transforms these markdown files into:

- Search indexes
- Knowledge graphs
- Navigation
- Recommendations
- RSS feeds
- Sitemaps
- JSON exports
