# Topics

Topics categorize what content is about.

Unlike themes, which represent ideas, topics represent concrete subject areas such as technology, music, photography, engineering, or baseball.

Every Atlas object should belong to one or more topics, allowing the knowledge graph to organize and surface related content naturally.
