# Drawing & Sketching

> **Translating thoughts into visual form.**

Drawing and sketching serve as both a creative outlet and a practical tool for visual problem-solving. Whether sketching physical component layouts for 3D printing, designing laser engraving vector paths, or drawing digitally, visual art connects imagination to tangible design.

## Core Areas of Interest

- **Vector & Laser Art Design**: Creating high-contrast line work optimized for laser engraving on slate and wood.
- **Visual Problem Solving**: Using quick sketches to brainstorm UI layouts, server rack wiring diagrams, and product ideas.
- **Digital Illustration**: Exploring digital drawing tablets and vector graphics software.
