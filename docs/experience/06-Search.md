# Search Experience Specification

> **Instant, zero-friction discovery across the entire knowledge graph.**

---

## Overview

The Search Experience in Atlas operates entirely client-side using `search.json`. Visitors can query by keyword, topic tag, or metadata type.

---

## Interface & Interactions

- **Keyboard Shortcut**: Pressing `/` or `Ctrl+K` opens the search overlay.
- **Real-Time Filtering**: Instant results matching titles, summaries, tags, and topics.
- **Categorized Results**: Grouped by Articles, Projects, Topics, and Library items.
